# Ameera 👗

**Ameera - AI Agent for Abaya Shopping on WhatsApp**

Ameera helps customers shop for Abayas easily on WhatsApp.

## What Ameera Does
- Greets customers with Salam
- Shows Abaya collection
- Shows Prices and Sizes
- Helps customers Order
- Connects to Human when needed

## Abaya Collection
1. Classic Black Abaya - N25,000 - Sizes: S, M, L, XL
2. Embroidered Luxury Abaya - N45,000 - Sizes: M, L, XL
3. Everyday Casual Abaya - N18,000 - Sizes: S, M, L

## How To Use
Type `Hi` to start
Type `1` to see Abayas
Type `2` to see Prices
Type `3` to Order
Type `4` to Talk to Human

## How To Order
1. Tell Ameera the Abaya number
2. Your Size
3. Your Name + Address in Abuja
Ameera will confirm your order.
